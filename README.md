
# API Practice Repository

This repository contains backend practice projects built while learning backend fundamentals.

## Tech Stack

* Node.js
* Express
* MongoDB (Mongoose)
* PostgreSQL
* Drizzle ORM
* Redis
* Docker
* JWT
* bcrypt
* Nodemailer
* Node `crypto`

---

## What Has Been Implemented

### Authentication System

* Signup with OTP verification
* Login with JWT
* Auth middleware
* Change password
* Forgot password (OTP reset)

### Memo CRUD API

* Create, read, update, delete memos
* Protected routes

### Redis Rate Limiting

* Custom middleware
* TTL-based request limiting
* Docker + Redis debugging

### Weather API

* External API integration
* Query parameter handling

### PostgreSQL + Drizzle

* Local Postgres connection
* Schema definition
* Insert and select queries

### Hashing Practice

* MD5
* SHA-256
* scrypt
* Salt usage
* Password verification logic

---

## Purpose

To deeply understand backend fundamentals, security concepts, and real-world API development without copy-paste learning.
